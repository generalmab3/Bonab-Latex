\section{اسکلت شبکه}
کد~\ref{lst:pytorch-model} یک شبکه پیش‌خور حداقلی است. ابعاد باید با روابط~\eqref{eq:model-input} و~\eqref{eq:model-output} یکی باشند.

\begin{latin}
\begin{lstlisting}[caption={\protect\lr{A minimal PyTorch skeleton for the energy PINN}},label={lst:pytorch-model}]
import torch
from torch import nn


class EnergyPINN(nn.Module):
    def __init__(self, n_in=6, n_out=4, width=64, depth=4):
        super().__init__()
        layers = [nn.Linear(n_in, width), nn.Tanh()]
        for _ in range(depth - 1):
            layers += [nn.Linear(width, width), nn.Tanh()]
        layers += [nn.Linear(width, n_out)]
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x)


def upper_lower_penalty(z, lower, upper):
    above = torch.relu(z - upper).pow(2)
    below = torch.relu(lower - z).pow(2)
    return (above + below).mean()
\end{lstlisting}
\end{latin}

\section{اسکلت باقیمانده فیزیک}
کد~\ref{lst:physics-loss} همان روابط فصل قبل را به عملیات تنسوری برمی‌گرداند.

\begin{latin}
\begin{lstlisting}[caption={\protect\lr{Physics residuals for power balance and battery dynamics}},label={lst:physics-loss}]
def physics_losses(model, batch, dt, e_max, eta_ch, eta_dis):
    prediction = model(batch["x"])
    p_grid, p_ch, p_dis, soc_next = prediction.split(1, dim=1)

    power_residual = (
        p_grid + batch["p_pv"] + p_dis
        - p_ch - batch["p_load"]
    )

    expected_soc = (
        batch["soc"]
        + eta_ch * p_ch * dt / e_max
        - p_dis * dt / (eta_dis * e_max)
    )
    soc_residual = soc_next - expected_soc

    loss_power = power_residual.pow(2).mean()
    loss_soc = soc_residual.pow(2).mean()
    loss_bounds = upper_lower_penalty(
        soc_next, batch["soc_min"], batch["soc_max"]
    )
    return prediction, loss_power, loss_soc, loss_bounds
\end{lstlisting}
\end{latin}

اگر معادله پیوسته افزوده شود، ورودی زمان باید \lr{requires\_grad} داشته باشد و مشتق با \lr{torch.autograd.grad} گرفته شود. برای مدل گسسته فعلی لازم نیست.

\section{داده}
حداقل فیلدها: زمان، بار، توان خورشیدی، وضعیت شارژ و در صورت استفاده، قیمت خرید و فروش. اگر داده واقعی نیست، شبیه‌ساز باید صریح باشد: پروفیل بار، مدل تابش، ظرفیت باتری، بازده، نویز و نحوه تقسیم افق.

قواعد اجباری آماده‌سازی:
\begin{enumerate}
  \item رد مقادیر ناممکن مانند وضعیت شارژ خارج از $[0,1]$ یا توان منفی تولید خورشیدی؛
  \item تقسیم زمانی، نه درهم‌آمیزی تصادفی نمونه‌های مجاور؛
  \item محاسبه میانگین و واریانس نرمال‌سازی فقط از آموزش؛
  \item نگهداری ترتیب زمانی برای ارزیابی چندگامی بعدی.
\end{enumerate}

\section{مدل‌های مقایسه}
حداقل دو مدل با معماری یکسان لازم است:
\begin{enumerate}
  \item شبکه داده‌محور با $\lambda_{P}=\lambda_{S}=\lambda_{c}=\lambda_{e}=0$؛
  \item شبکه فیزیک‌آگاه با رابطه~\eqref{eq:total-loss}.
\end{enumerate}
در صورت امکان، یک حل‌کننده بهینه‌سازی کلاسیک روی همان افق به‌عنوان مرجع سوم اضافه شود. مقایسه فقط وقتی منصفانه است که داده، معماری، بودجه تکرار و مجموعه آزمون یکی باشند.

\section{معیارها}
خطای پیش‌بینی:
\begin{equation}
  \mathrm{MSE}=\frac{1}{N}\sum_{i=1}^{N}
  \left\|\hat{\bm{y}}_i-\bm{y}_i\right\|_2^2.
  \label{eq:mse}
\end{equation}
باقیمانده توازن:
\begin{equation}
  E_{P}=\frac{1}{N}\sum_{i=1}^{N}|r_P(t_i)|.
  \label{eq:physics-metric}
\end{equation}
نرخ نقض قید:
\begin{equation}
  R_{v}=\frac{N_{\mathrm{violated}}}{N}\times 100.
  \label{eq:violation-rate}
\end{equation}
هزینه بهره‌برداری و زمان استنتاج نیز باید گزارش شوند. هر عدد باید میانگین چند بذر و یک شاخص پراکندگی داشته باشد.

\section{طرح آزمایش}
\begin{enumerate}
  \item آموزش دو مدل با تقسیم یکسان؛
  \item تنظیم وزن فیزیک روی اعتبارسنجی؛
  \item ارزیابی روی آزمون ندیده؛
  \item تکرار با داده کمتر و با نویز بیشتر؛
  \item تحلیل حساسیت $\lambda_P$؛
  \item گزارش جدول واحد برای دقت، فیزیک، نقض، هزینه و زمان.
\end{enumerate}

\section{آمادگی برای دفاع از همین فصل}
داور معمولاً می‌پرسد کد کجاست، داده از کجا آمده و چرا هنوز عدد ندارید. پاسخ درست این است که گزارش عمداً پروتکل را از نتیجه جدا کرده است؛ اسکلت کد در همین فصل است؛ و هر عدد بعد از اجرا به همین جدول وارد می‌شود. این پاسخ ضعیف نیست، اگر دانشجو واقعاً بتواند کد را توضیح دهد و یک آزمایش کوچک را نشان بدهد.
