\section{اسکلت جایگزین پای‌تورچ}
کد~\ref{lst:pytorch-model} اجرا نشده است و عرض ۶۴ آن با شبکه ۴۸ نورونی آزمایش فرق دارد.

\begin{latin}
\begin{lstlisting}[caption={\protect\lr{Optional PyTorch skeleton; not used for Table results}},label={lst:pytorch-model}]
import torch
from torch import nn


class EnergyPINN(nn.Module):
    def __init__(self, n_in=6, n_out=4, width=64, depth=4):
        super().__init__()
        layers = [nn.Linear(n_in, width), nn.Tanh()]
        for _ in range(depth - 1):
            layers += [nn.Linear(width, width), nn.Tanh()]
        layers += [nn.Linear(width, n_out)]
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x)


def upper_lower_penalty(z, lower, upper):
    above = torch.relu(z - upper).pow(2)
    below = torch.relu(lower - z).pow(2)
    return (above + below).mean()
\end{lstlisting}
\end{latin}

\section{اسکلت باقیمانده فیزیک}
کد~\ref{lst:physics-loss} همان روابط فصل قبل را به عملیات تنسوری برمی‌گرداند.

\begin{latin}
\begin{lstlisting}[caption={\protect\lr{Physics residuals for power balance and battery dynamics}},label={lst:physics-loss}]
def physics_losses(model, batch, dt, e_max, eta_ch, eta_dis):
    prediction = model(batch["x"])
    p_grid, p_ch, p_dis, soc_next = prediction.split(1, dim=1)

    power_residual = (
        p_grid + batch["p_pv"] + p_dis
        - p_ch - batch["p_load"]
    )

    expected_soc = (
        batch["soc"]
        + eta_ch * p_ch * dt / e_max
        - p_dis * dt / (eta_dis * e_max)
    )
    soc_residual = soc_next - expected_soc

    loss_power = power_residual.pow(2).mean()
    loss_soc = soc_residual.pow(2).mean()
    loss_bounds = upper_lower_penalty(
        soc_next, batch["soc_min"], batch["soc_max"]
    )
    return prediction, loss_power, loss_soc, loss_bounds
\end{lstlisting}
\end{latin}

این دو قطعه برای انتقال بعدی به پای‌تورچ مانده‌اند. گرادیان آزمایش فعلی به‌صورت صریح در همان اسکریپت \lr{NumPy} نوشته شده است.

\section{داده مصنوعی}
شبیه‌ساز \lr{code/simulate.py} بیست‌ویک شبانه‌روز ساعتی می‌سازد. بار یک الگوی روزانه با قله عصر، تولید خورشیدی فقط در روز، و قیمت خرید در ساعات اوج بالاتر است. برنامه مرجع با قاعده حریصانه ساخته می‌شود: مازاد خورشید باتری را تا سقف شارژ می‌کند، کمبود با دشارژ جبران می‌شود و باقی‌مانده از شبکه می‌آید. ظرفیت باتری $20$ کیلووات‌ساعت، بازده شارژ و دشارژ $0.95$ و حدود وضعیت شارژ $[0.20,0.90]$ است.

برای آنکه مؤلفه فیزیک کاری برای انجام داشته باشد، به برچسب‌های مجموعه آموزش نویز گاوسی با انحراف معیار $0.35$ اضافه شد. مجموعه آزمون بدون این نویز مانده است. تقسیم زمانی است: ۶۰ درصد آموزش، ۲۰ درصد اعتبارسنجی و ۲۰ درصد آزمون؛ یعنی ۱۰۲ ساعت آزمون از ۵۰۴ ساعت کل. بذر تولید داده برابر ۷ است.

تقسیم زمانی است، نه درهم‌آمیزی تصادفی ساعت‌های مجاور. تولید خورشیدی نامنفی بریده می‌شود و وضعیت شارژ مرجع در بازه $[0.20,0.90]$ می‌ماند. در اجرای گزارش‌شده ورودی‌ها استانداردسازی نشدند؛ زمان فقط به ساعت شبانه‌روز در بازه $[0,1]$ نگاشته شد. این ساده‌سازی در خوانش نتایج باید در نظر باشد. مجموعه اعتبارسنجی ساخته شد اما برای تنظیم وزن به کار نرفت؛ وزن فیزیک پیش از اجرا ثابت ماند.

\section{مدل‌های مقایسه}
دو مدل با معماری یکسان آموزش داده شد:
\begin{enumerate}
  \item شبکه داده‌محور با $\lambda_{P}=\lambda_{S}=\lambda_{c}=\lambda_{e}=0$؛
  \item شبکه فیزیک‌آگاه با خطای داده به‌علاوه باقیمانده توان، دینامیک باتری و جریمه حدود.
\end{enumerate}
مرجع سومِ بهینه‌سازی کلاسیک در این نسخه اجرا نشد. دو شبکه معماری، داده، تعداد دور و مجموعه آزمون یکسان داشتند. مؤلفه اقتصادی رابطه~\eqref{eq:economic-loss} فقط به‌عنوان معیار پس از آموزش محاسبه شد و داخل گرادیان نبود.

\section{معیارها}
خطای پیش‌بینی:
\begin{equation}
  \mathrm{MSE}=\frac{1}{N}\sum_{i=1}^{N}
  \left\|\hat{\bm{y}}_i-\bm{y}_i\right\|_2^2.
  \label{eq:mse}
\end{equation}
باقیمانده توازن:
\begin{equation}
  E_{P}=\frac{1}{N}\sum_{i=1}^{N}|r_P(t_i)|.
  \label{eq:physics-metric}
\end{equation}
نرخ نقض قید:
\begin{equation}
  R_{v}=\frac{N_{\mathrm{violated}}}{N}\times 100.
  \label{eq:violation-rate}
\end{equation}
هزینه بهره‌برداری نیز گزارش شده است. در این نسخه یک بذر ثابت استفاده شده و پراکندگی چنداجرایی گزارش نشده است.
